# 指标目录（业务方向导航）

> 635 个指标的**业务分类索引**，用于把用户话术快速折叠成检索关键词。
> 这不是权威 id 表——落参数前必须用 `metric_search` 确认。
> 全量 `id,metric_name_cn` 快照见 `assets/metric-catalog.csv`。

## 0. 怎么用这份文档

1. 用户话术 → 在下面找对应业务方向（"宽带升级" → 千兆 / FTTR / 速率档位）；
2. 从该方向挑 1-3 个**关键词**；
3. 用 `metric_search(keyword=...)` 确认 id 与全名；
4. 若命中多条语义相近的指标，**都查一遍**再在回答里说明差异（这比猜一个更安全）。

## 4. 质量与感知（被问"体验好不好"时）

- **上网质量**：`上网质量表现值`（130）、分运营商对比（118-120）、
  领先值（121-123）；分场景满意度（131-137：速度/稳定性/重点场景/游戏/视频/电视/网页）。
- **安装维修**：表现值（138-140：装机/故障维修/移机）、分运营商对比（124-129）、
  影响感知占比（142/144/145）。
- **FTTR 满意度**：146-149（整体/网络质量/终端质量/安装维修）。

这些都是**表现值/满意度**口径，通常是评分或指数，不要当户数用。

## 8. 检索技巧（实测有效）

| 用户说法 | 建议关键词 | 说明 |
|---|---|---|
| 宽带用户 / 家宽用户 | `宽带` 或 `家庭宽带` | 命中 44+ 条，取 id 1 为主 |
| 千兆 | `千兆` | 51 条，注意区分"用户数"与"占比" |
| FTTR | `FTTR` | 20 条（limit 内），需要更多就加关键词 |
| 组网 | `智能组网` | 只搜 `组网` 会混入"问题智能组网路由器"等质量类 |
| 普及率 / 渗透率 / 占比 | `占比` 或 `率` | 这类是比率；绝对量指标名里没有"率/占比" |
| 投诉多不多 | `投诉` | 72 条，建议加业务限定 |
| 装维慢 / 装机 | `装维` 或 `装机` | |
| 网络差 / 卡顿 | `上网质量` 或 `时延` | 前者是感知评分，后者是技术指标 |
| 断网 / 掉线 | `中断` | |

> `metric_search` 是 SQL `LIKE '%kw%'` 模糊匹配，**不区分大小写**（SQLite 默认对 ASCII 不敏感），
> 中文按字面匹配。空关键词会返回前 20 条（等于浏览）。
