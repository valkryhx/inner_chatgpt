# 数据分析工作流

当用户要求「分析这份数据 / 统计 / 画图 / 计算指标」时按下面步骤执行。

## 步骤

1. **确认数据位置**：先用 `list_files` 查看 workspace，再用 `file_read` 读取目标文件的前几十行，确认列名与分隔符。
2. **写分析脚本**：用 `file_write` 在 workspace 写一个 Python 脚本（例如 `analysis.py`），
   读取数据、计算指标、打印结构化结果。
3. **执行并验证**：用 `code_run`（type=python）运行脚本；检查退出码是否为 0、输出是否符合预期。
4. **修正**：若报错，读错误信息修正脚本（用 `file_patch` 局部改），再次运行，禁止原样重复。
5. **汇报**：把关键结论用文字总结给用户；如需图表，返回平台约定的 chart 结构，而不是贴原始 JSON。

## 约定

- 所有文件都放在个人 workspace 内，不要访问系统路径。
- 大数据文件只读取需要的行/列，避免一次读入全部内容。
- 计算结果以 `code_run` 的真实输出为准，不要凭记忆编造数字。
- 可用 `${SKILL_DIR}` 引用本 Skill 目录（当前为只读模板目录）。
