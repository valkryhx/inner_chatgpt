# 赞/踩图标替换为 claude.ai 样式

> 日期：2026-11-11　状态：已实施并验证
> 起因：Hlaudz 助手消息下方的赞/踩图标手绘描边造型粗糙，改用仓库内 claude 页面自带的官方图标。

## 0. 结论

`frontend/src/components/MessageList.tsx` 里赞/踩两个图标的 `d` 由手绘描边路径
换成从 claude.ai 页面图标字体提取的**实心轮廓**，并新增 `SolidIcon` 组件承载
（`fill="currentColor"` + `fillRule="evenodd"`），其余（复制/朗读/重试）保持原描边样式不变。

真实浏览器验证：图标渲染正确、无 console 报错、其余图标未被误改。

## 1. 图标从哪来

claude 页面（`claude_html/黄仁勋出轨传闻 - Claude.html`）的赞/踩**不是内联 SVG**，
而是私用区（PUA）码位由图标字体渲染：

| 位置 | 属性 | 码位 |
|---|---|---|
| 赞（回复很好） | `aria-label="回复很好"` | **U+E0FB** |
| 踩（回复不佳） | `aria-label="回复不佳"` | **U+E0F9** |

页面 CSS 里声明了一组 `Anthropicons-Variable` 字体（42 个 woff2，分片加载）。
逐个下载并扫描 `cmap` 后，**同时包含这两个码位**的是
`c0f671921-BUNaxviL.woff2`（479 个字形，`unitsPerEm=1000`，内部家族名 `Anthropicons RVRN`）。
另一个常见的 `cc27851ad-DDVos-BJ.woff2` 只有 `U+E11D`，不是目标文件——
这是第一次找错文件的原因。

## 2. 提取与归一

用 fontTools 把字形轮廓转成 SVG path，并按包围盒缩放到标准的 `0 0 24 24` 视口
（留 0.7 内边距、y 轴翻转、xy 等比缩放后居中），最后把坐标压到两位小数：

```python
import re
from fontTools.ttLib import TTFont
from fontTools.pens.svgPathPen import SVGPathPen
from fontTools.pens.transformPen import TransformPen
from fontTools.pens.boundsPen import BoundsPen
from fontTools.misc.transform import Transform

f = TTFont("work/_font/all/c0f671921-BUNaxviL.woff2")
gs, cmap = f.getGlyphSet(), f.getBestCmap()
BOX, PAD = 24.0, 0.7

def fmt(v):
    s = ("%.2f" % v).rstrip("0").rstrip(".")
    return "0" if s in ("", "-0") else s

def round_path(d):
    return re.sub(r"-?\d+\.\d+|-?\d+", lambda m: fmt(float(m.group(0))), d)

for cp in (0xE0FB, 0xE0F9):
    gn = cmap[cp]
    bp = BoundsPen(gs); gs[gn].draw(bp)
    x0, y0, x1, y1 = bp.bounds
    w, h = x1 - x0, y1 - y0
    scale = (BOX - 2 * PAD) / max(w, h)
    tx = (BOX - w * scale) / 2 - x0 * scale
    ty = (BOX + h * scale) / 2 + y0 * scale      # y 翻转：y_svg = ty - y*scale
    pen = SVGPathPen(gs)
    gs[gn].draw(TransformPen(pen, Transform().translate(tx, ty).scale(scale, -scale)))
    print(hex(cp), len(round_path(pen.getCommands())), round_path(pen.getCommands()))
```

结果：U+E0FB → 1,165 字符，U+E0F9 → 1,155 字符（不压小数时各约 3.9 K，压到两位小数后降 70%）。

## 3. 代码改动

`MessageList.tsx`：

- 新增 `SolidIcon`：`fill="currentColor"`、`fillRule="evenodd"`、`clipRule="evenodd"`、无 `stroke`；
- `ICON_UP` / `ICON_DOWN` 换成提取出的路径，并加注释写明来源（否则这两串数据无法追溯）；
- 两个按钮从 `<ActionIcon>` 改为 `<SolidIcon>`，标题与 `disabled` 状态不变。

之所以需要 `evenodd`：字形是**单条 path 含两个子路径**（外轮廓 + 内孔），
两种填充规则在本例渲染结果相同，但 `evenodd` 对子路径绕向不敏感，更稳。
