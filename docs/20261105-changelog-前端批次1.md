> 一句话：只换设计 token 和全局基样式，**零结构改动**，页面从「冷白 SaaS 模板」变成「暖纸 + 陶土」。

## 一、本轮做了什么

严格限定在「批次 1」范围内 —— **不动任何组件结构、不改任何 TSX 布局逻辑**，
只替换颜色、字体、圆角、阴影、间距 token 与全局基样式。

| 类别 | 内容 |
|---|---|
| Token | 新建 `--canvas/--surface/--surface-2/--line/--line-strong/--ink/--ink-2/--muted/--clay/--btn/--press/--clay-soft/--ok/--warn/--danger` |
| 字体 | `--font-sans` / `--font-serif` / `--font-mono`；正文 14px → **15px**，行高 1.72 |
| 尺度 | `--r-sm/md/lg/xl`、`--shadow-1/2`、`--ease` |
| 全局 | `::selection`、`:focus-visible`、滚动条、`caret-color`、`prefers-reduced-motion` |
| 兼容 | 保留旧变量名（`--panel/--accent/--text/--border` 等）作为别名，确保 TSX 内联样式不炸 |

涉及文件：**只有 1 个** —— `frontend/src/styles/index.css`（376 → 500 行）。

## 二、关键决策与实测数据

### 2.1 主按钮不能用 `--clay` 做底

设计文档里已预警，实施时用脚本复核确认：

| 配色 | 对比度 | 结论 |
|---|---|---|
| `#fff` on `#d97757`（原 clay） | **3.12:1** | ❌ 不达标 |
| `#fff` on `#b25334`（`--btn`） | **5.02:1** | ✅ 采用 |
| `#fff` on `#a84a28`（`--press`） | **5.71:1** | ✅ hover/active |

所以主按钮统一用 `--btn`，`--clay` 只用于焦点环、图形点缀。全部色值实测：

```
ink/canvas 16.66   ink2/canvas 10.34   muted/canvas 5.15   muted/surface 4.92
muted/surf2 4.67   white/btn 5.02      white/press 5.71     danger/canvas 4.57
ok/canvas 4.23(图形)  warn/canvas 3.75(图形)  clay/canvas 3.20(图形)
```

### 2.2 侧栏比主区「深」而不是「浅」

原来侧栏纯白、内容灰 → 视线被左侧吸走。现在侧栏 `--surface(#f5f4ed)`、主区 `--canvas(#faf9f5)`，
让工作区成为最亮的地方。

### 2.3 正文列宽 820 → 720px

配合 15px 字号，一行约 68ch，落在 skill 要求的 65–75ch 区间。

## 三、顺带修掉的两个真实缺陷

批次 1 不改结构，但回归时发现两个**必须修**的响应式问题（否则等于把一个更漂亮的坏页面交出去）：

| 缺陷 | 现象 | 修复 |
|---|---|---|
| 移动端侧栏不折叠 | 390px 下侧栏仍占 264px，主区被挤成 70px 宽的一条竖排文字 | `<720px` 时改为上下堆叠、侧栏最多 32vh，主区占满 |
| 中屏标题被压成 4 字 | 768px 下侧栏 264px，主区只剩 504px，标题截断成「2026年1-7月 全国宽带用...」 | `721–900px` 侧栏 208px，隐藏 badge / 模型标签，压缩间距 |
