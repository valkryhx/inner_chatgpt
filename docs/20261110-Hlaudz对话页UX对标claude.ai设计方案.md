# Hlaudz 对话页 UX 对标 claude.ai 设计方案

> 日期：2026-11-10
> 分支：`feat/claude-like-ux`
> 状态：实施中（配色沿用 Hlaudz 现有暖纸/陶土，不改）
> 参考页：`https://claude.ai/chat/...`（用户已登录的真实会话页，经 Edge 远程调试抓取）

## 1. 目标

把 Hlaudz 的对话页骨架对齐 claude.ai 的 UX 结构与按钮位置：

- 左侧 288px 固定导航侧栏（新建 / 搜索 / 项目 / Artifacts / Code / 自定义 + 分组会话列表 + 底部用户条）；
- 顶部 45px 标题栏（会话标题 + 下拉、右侧分享）；
- 中央 768px 消息列，用户消息右对齐气泡；
- 底部 768×44 圆角输入框（左 `+` 上传、右侧语音组），下方一行「免责声明 + 模型选择」；
- 助手消息下方一行操作按钮（复制 / 朗读 / 赞 / 踩 / 重试）。

**不做的**：语音模式、分享、搜索、项目、Artifacts、Code 的真实功能——只做按钮与位置，点击给「未实现」提示或禁用。配色、字体沿用 Hlaudz 现有设计系统。

## 3. 实施步骤

1. `styles/index.css` 追加「对话页骨架」层（不改配色变量）：侧栏、顶栏、消息列、输入框、底栏。
2. `Sidebar.tsx` 重构为导航 + 分组 + 用户条；保留重命名/删除/设置/登出能力。
3. `App.tsx` 顶栏改为「标题按钮 + 更多 + 分享」，模型选择移到底部说明行。
4. `Composer.tsx` 改为单行 pill + 右侧图标组；语音三项为占位（禁用 + tooltip）。
5. `MessageList.tsx` 增加助手消息操作行（复制真实，朗读/赞/踩/重试占位）。
6. 本地构建 + 截图比对。

## 4. 风险

- 现有 E2E/UI 断言若依赖旧类名会失效，需要跑一遍前端测试与手测。
- 侧栏从「会话列表」扩成「导航 + 分组」，需要处理无会话/空分组。
- 模型选择器移动位置后，`disabled` 逻辑（streaming）要跟着搬。

## 6. 实施结果（2026-11-11）

已完成并通过 `tsc --noEmit` / `npm test` / `npm run build`，本机截图比对通过。

| 区域 | 落地情况 |
| --- | --- |
| 侧栏 | 288px；顶部「☰ + Hlaudz」；导航：新建（Ctrl Shift O）/ 搜索 / 项目 / Artifacts / Code / 自定义；分组标题「已置顶」「对话和任务」+ 排序按钮；会话行 32px、圆角 8、hover 出现删除；底部用户条 |
| 顶栏 | 45px；左侧「标题 + ▾」按钮；右侧「文件 / 分享」 |
| 消息列 | 768px 居中，左右 16 内缩；用户气泡圆角 12、内边距 12×16、最大宽 85% |
| 操作行 | 助手消息下方：复制（真实）/ 朗读 / 赞 / 踩 / 重试（占位，disabled） |
| 输入框 | 768×44 圆角 14，内边距 8，`＋` 在左；右侧空闲时是「麦克风 / ▾ / 语音模式」占位，有内容时切换为发送箭头；生成中变红方块停止 |
| 底部说明行 | 左「Hlaudz 可能会出错…」+ 上下文占用；右模型选择（无「模型」前缀） |

占位（点击无效，`disabled` + tooltip 标注「未实现」）：搜索、项目、Artifacts、Code、分组排序、语音输入、语音模式、分享、朗读/赞/踩/重试、隐藏侧栏以外的导航项。

已知未做：侧栏折叠后没有真正的图标态（收起即隐藏，左上角有恢复按钮）；Claude 的 Code/Artifacts 侧栏面板属于独立产品面，不在此次范围。
